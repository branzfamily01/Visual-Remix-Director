01 / Reference Harvest

好きなサイトを、
そのまま真似しない。

「サイトAが好き」ではなく、何が好きかまで切り分けるための参照ボードです。画像・スクリーンショット・URLを集めます。

ADD REFERENCE
または
0 REFERENCES

まず3つ集める

構図・文字・質感など、違う強みを持つ参照を3〜6個集めるとリミックスしやすくなります。

02 / Reference Decomposition

「どこを借りるか」を
部品単位で決める。

各デザイン要素ごとに参照元を1つ選び、採用点と変更点を書きます。コピーではなく、意思決定の記録です。

03 / Remix Direction

断片をまとめて、
ひとつの世界観にする。

ここで参照元から離れます。「誰に」「どんな印象を」「何を避けて」見せるのかを言語化します。

3つの方向性ワード
COLOR DIRECTION

5色だけ決める

色を増やしすぎない方が、複数参照を混ぜてもまとまります。
