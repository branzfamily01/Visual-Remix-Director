# Visual Remix Director

複数のWebデザイン参照を「構図・文字・色・質感・画像・動き・UI」へ分解し、独自のRemix Direction、Design Contract、AI実装プロンプトへ変換する静的Webアプリです。

## Features
- Reference Harvest: 画像 / URL / メモの収集
- Reference Decomposition: 要素ごとの参照元・採用点・変更点
- Remix Direction: 目的、対象、3ワード、Signature、避けるもの、5色パレット
- Design Contract 自動生成
- Claude Code / ChatGPT / Cursor / Lovable向け Build Prompt
- localStorage + IndexedDB 自動保存
- JSONバックアップ / 復元
- PWA / オフラインマニュアル
